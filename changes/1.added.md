Answer a question from the passages retrieved for it, with `KnowledgeGraph.query`, `Retriever.query`, `Retriever.aquery`, and `raganite query`. The answer uses only those passages.

Indexing reports, retrieval results, and query answers now include token and timing totals by stage. `raganite query --format json` prints that usage, and HotpotQA and LoCoMo runs store it on each question.

Hugging Face chat and embeddings, including hosted endpoints, and Ollama chat are optional providers. Install them with `uv sync --extra huggingface` or `uv sync --extra ollama`.

Indexing now defaults to free extraction, so the model names entities and relations from the text. Pass `--schema`, or set `schema_mode` to `fixed`, to keep the previous built-in code schema.

`load_config()` and the CLI load `.env` from the working directory when it is present, and they pick up `raganite.json` or `raganite.toml` there when no config path is given. An explicit dotenv path must exist. `--no-env-file` has been removed.

Azure OpenAI v1 clients accept `AZURE_OPENAI_ENDPOINT` and `AZURE_OPENAI_API_KEY`, and also `OPENAI_API_KEY`, `OPENAI_API_BASE`, and `OPENAI_BASE_URL`, so those values do not have to be copied between names.

# Future work

The following capabilities are planned for exploration. They are not currently
available as built-in integrations, and no release dates are committed.

## Expose Raganite through MCP

- Provide a Model Context Protocol (MCP) server so compatible assistants and
  applications can use Raganite's indexing and graph retrieval capabilities.



## Support Llama LLMs and embeddings

- Add built-in client support for Llama language models and embedding models
  served through compatible runtimes or providers.
